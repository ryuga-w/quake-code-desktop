# @mrquake/quakecode-ai

Quake Code AI is the provider and model layer behind Quake Code.

It handles:
- model/provider registration
- OAuth and API-key auth
- provider-specific request/stream handling
- model discovery and capability metadata

## Install

```bash
npm install @mrquake/quakecode-ai
```

## Purpose

This package is intended for Quake Code and related tooling in the Quake ecosystem.
