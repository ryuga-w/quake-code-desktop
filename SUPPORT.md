# Support

## Questions and setup help

Use [GitHub Discussions](https://github.com/ryuga-w/quake-code-desktop/discussions) for installation questions, workflow ideas, and help understanding configuration. Include your Windows version, Quake Code version, and the relevant provider or tool without sharing secrets.

## Bugs

Open a [bug report](https://github.com/ryuga-w/quake-code-desktop/issues/new?template=bug_report.yml) when behavior is reproducible. Before posting:

1. Check existing issues.
2. Retry on the newest release or `main` when practical.
3. Remove API keys, access tokens, project secrets, and personal data from logs or screenshots.
4. Include concise reproduction steps and the expected behavior.

## Feature proposals

Use the [feature request form](https://github.com/ryuga-w/quake-code-desktop/issues/new?template=feature_request.yml) for a concrete product gap. Describe the problem first; proposed UI or implementation details are helpful but optional.

## Security

Do not post suspected vulnerabilities or exposed credentials in Issues or Discussions. Follow the private reporting process in [SECURITY.md](SECURITY.md) and rotate any exposed secret immediately.

This is a community-maintained open-source project; support and response times are best effort.
